# Turnitin Academic Humanizer Skill (`turnitin-academic-humanizer`)

An Agent Skill (`SKILL.md`) designed for AI assistants (Claude Code, Antigravity, Cursor, Codex, ChatGPT) to rewrite and polish academic papers, reducing **Turnitin Similarity Scores** and **Turnitin AI Writing Detection Rates** while preserving scholarly rigor.

## Features
- **Dual-Engine Optimization**: Targets both Turnitin N-gram similarity matching and AI detection (Perplexity & Burstiness).
- **Structural Reconstruction**: Reorganizes logic chains (`Cause ↔ Effect`), merges/splits clauses, and converts nominalizations into active verbs.
- **Burstiness Injection**: Enforces deliberate sentence-length contrast and removes formulaic paragraph endings.
- **De-LLM Filter**: Strips high-frequency AI vocabulary and participial tail clauses (`..., thereby V-ing`).
